準備完了
コマンド一覧（1行1コマンド、座標は左上が 0,0。グリッドは50px刻み） 
// コメント
color #ff0000          線・文字・バケツの色
fillcolor #00aaff      図形の塗り色
width 5                線の太さ
alpha 0.6              不透明度 (0〜1)
font 32                文字サイズ(px)
bg #ffffff             背景色で全面を塗る
clear                  白で全消去
size 1024 768          キャンバスサイズ変更

line x1 y1 x2 y2
polyline x1 y1 x2 y2 x3 y3 ...
polygon  x1 y1 x2 y2 x3 y3 ... [mode]
rect x y w h [mode]
roundrect x y w h r [mode]
circle cx cy r [mode]
ellipse cx cy rx ry [角度deg] [mode]
arc cx cy r 開始deg 終了deg
curve x1 y1 cx cy x2 y2            2次曲線
bezier x1 y1 c1x c1y c2x c2y x2 y2  3次曲線
dot x y [r]            点（塗り＝線の色）
fill x y [色]          バケツ塗りつぶし
text x y "文字列"

[mode] = stroke(既定) | fill | both

JavaScriptからも操作できます：paint.run("circle 100 100 40 fill")、paint.undo()、paint.clear()、paint.toDataURL()、paint.getState()
