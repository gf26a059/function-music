# 関数ミュージック

数式のグラフがそのまま音楽になる、6つの部屋。すべてブラウザの Web Audio で合成しています。

| 部屋 | ページ | 雰囲気 |
| --- | --- | --- |
| 関数トランス | `trance.html` | スーパーソウのアルペジオ、ネオンの立方体 |
| 関数ビッグバンド | `bigband.html` | 7/4 の高速スウィング、ホーンのキメ |
| 関数ウィップ | `whip.html` | 歪んだベースとムチの一撃、クロームの立方体 |
| 関数の雨音 | `rain.html` | 低い和音のうねりとハンドパン、夜の雨 |
| 氷チル | `ice.html` | 冷たいピアノと鉄琴、かまくらと鈴 |
| 関数の深海 | `deep.html` | 泡の低音、溶けたピアノ、遠いオーケストラ |

各ページの式は `t`（ステップ）・`b`（拍）・`bar`（小節）・`k`（小節内の位置）を変数に使えます。式は自前のパーサで評価しているので `eval` は使っていません。

ビルド不要の静的サイトです。`index.html` を開くか、GitHub Pages で公開してください。
